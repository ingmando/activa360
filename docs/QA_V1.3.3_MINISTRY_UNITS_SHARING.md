# QA v1.3.3 — Unidades Ministeriales + Sharing

## 1. Unidades ministeriales
- [ ] Entrar como Pastor.
- [ ] Abrir Equipos y unidades ministeriales.
- [ ] Abrir `Unidades ministeriales`.
- [ ] Crear una pareja con dos personas del mismo nivel.
- [ ] Elegir representante.
- [ ] Confirmar que ya no aparecen duplicadas como unidades individuales.
- [ ] Desvincular y comprobar que vuelven a aparecer individualmente.

## 2. Persona y mentoría
- [ ] Crear/editar una persona.
- [ ] Asignar nivel 1, 2 o 3.
- [ ] Asignar mentor/cobertura.
- [ ] Confirmar aparición en Equipos y Árbol.

## 3. Reunión de 12
- [ ] Crear reunión como Borrador.
- [ ] Confirmar que no aparecen botones WhatsApp/Copiar enlace.
- [ ] Completar un reporte interno desde Borrador.
- [ ] Abrir reunión.
- [ ] Confirmar botones de compartir.
- [ ] En pareja, validar dos preguntas de devocional y una sola de diezmo/ofrenda/altar.
- [ ] Revisar card a 360–430 px: ningún elemento debe salir del viewport.
- [ ] Revisar desktop: tabla, primera columna, acciones y scroll horizontal.

## 4. Enlace público
- [ ] Generar enlace.
- [ ] Abrir en incógnito, sin autenticación.
- [ ] Confirmar nombre de la unidad.
- [ ] Diligenciar devocionales personales y hábitos de unidad.
- [ ] Guardar y volver a abrir.
- [ ] Regenerar enlace y confirmar que el anterior deja de funcionar.
- [ ] Cerrar reunión y confirmar que el enlace público queda bloqueado.

## 5. WhatsApp
- [ ] Representante con teléfono registrado.
- [ ] Pulsar WhatsApp.
- [ ] Confirmar texto con nombre de unidad y link.
- [ ] Si no hay teléfono, validar que WhatsApp permita escoger contacto o copiar link manualmente.

## 6. Compatibilidad
- [ ] Abrir reuniones históricas con reportes `leaderId` previos.
- [ ] Confirmar que el devocional legado se atribuye a la persona principal.
- [ ] No ejecutar `0002_seed_demo.sql` sobre la D1 piloto con datos reales.
