# QA — Activa 360 v1.3.1 UX Polish

## Reunión de 12
- [ ] El resumen muestra 4 métricas en una fila en escritorio.
- [ ] El resumen muestra 2×2 en móvil.
- [ ] Los números no dominan desproporcionadamente el texto.
- [ ] La matriz desktop conserva encabezados al hacer scroll vertical.
- [ ] La columna Líder permanece visible al hacer scroll horizontal.
- [ ] En móvil se muestran cards de líderes y no la matriz completa.

## Navegación
- [ ] Sidebar fijo en escritorio durante scroll largo.
- [ ] Sidebar tablet abre/cierra con scrim.
- [ ] Barra inferior móvil permanece visible.
- [ ] Menú Más abre como bottom sheet y se cierra tocando fuera.

## Perfil
- [ ] Abre desde avatar.
- [ ] Cierra tocando fuera.
- [ ] Cierra con Escape en escritorio.
- [ ] Perfil y Cambiar contraseña no dejan dropdown abierto detrás.

## Personas
- [ ] Desktop conserva tabla.
- [ ] Móvil transforma resultados en cards.
- [ ] No existe overflow horizontal normal.

## Árbol
- [ ] Filtros por generación funcionan.
- [ ] Drill-down funciona.
- [ ] Breadcrumb refleja la cobertura actual.
- [ ] Volver retorna al nivel anterior.

## PWA
- [ ] La app puede instalarse desde el origen estable.
- [ ] Al publicar una versión posterior aparece `Nueva versión disponible`.
- [ ] `Actualizar ahora` recarga a la versión nueva.
- [ ] Si Badging API está disponible, el icono recibe contador de alertas.

## Regresión
